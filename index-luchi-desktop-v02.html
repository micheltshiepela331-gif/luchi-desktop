Bienvenue sur Luchi Desktop

Un bureau web léger inspiré des ordinateurs. Ouvre les fenêtres, sélectionne tes fichiers et utilise ton clavier Bluetooth.

Personnaliser le bureau

ThèmeChoisis une apparence claire ou sombre.
Fond d’écranChange l’ambiance du bureau.
Clavier BluetoothPour changer AZERTY/QWERTY, ouvre les réglages Android du clavier physique, s’ils existent.
Plein écranLe navigateur doit autoriser cette fonction.
Raccourcis clavierCtrl+E : fichiers · Ctrl+, : paramètres · Échap : fermer la fenêtre active.

Les préférences de thème et de fond sont mémorisées sur cet appareil. Cette interface reste un site web et ne remplace pas Android.

Applications web
Ces raccourcis ouvrent des sites web. Le lancement direct de toutes les applications Android demande une version native.
À propos de Luchi Desktop

Luchi Desktop 0.2

Prototype HTML, CSS et JavaScript destiné à donner à une tablette Android une apparence de bureau.

Améliorations : fenêtres déplaçables, redimensionnement, plusieurs fenêtres, sélection de fichiers, recherche, thèmes et raccourcis clavier.

Limites : l’accès aux fichiers se fait uniquement après sélection. Le lancement des applications natives et la configuration système du clavier nécessitent Android natif.
